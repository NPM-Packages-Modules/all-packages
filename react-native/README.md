# React Native packages

![React Native](https://img.shields.io/badge/React_Native-20232A?style=flat&logo=react&logoColor=61DAFB)

React Native (mobile) npm packages live here. Each subdirectory is its own repo under [NPM-Packages-Modules](https://github.com/orgs/NPM-Packages-Modules/repositories).

## Layout

```
react-native/<package>/
  package.json
  src/
  README.md
  LICENSE
```

## Development

```bash
npm run build --workspace=react-native/<package>
```

Sibling: [`../mern`](../mern) (backend), [`../flutter`](../flutter) (Dart).
