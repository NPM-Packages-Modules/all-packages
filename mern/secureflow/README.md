# secureflow

Automated security middleware orchestration.

## Features

- rate limiting
- XSS protection
- SQL/NoSQL injection guards
- header hardening
- suspicious activity detection

## Example

```ts
import { secureflow } from "@mr-aftab-ahmad-khan/secureflow";

secureflow.protect(app);
```

## Why

Security setups are inconsistent across projects.
