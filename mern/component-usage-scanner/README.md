# component-usage-scanner

**Topics:** react · dead-code · audit · mern-packages · merndev · nodejs · npm-pm · typescript

Find **unused React components, hooks, and pages** in your frontend architecture.

## Install

```bash
npm install component-usage-scanner
```

## API

```typescript
import { componentUsageScanner } from "component-usage-scanner";

componentUsageScanner.scan(["UserModal", "ProfileCard"]);
```
