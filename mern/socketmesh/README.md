# socketmesh

Simplify scalable real-time event communication.

## Features

- room orchestration
- event namespaces
- reconnect handling
- clustered sockets
- event replay

## Example

```ts
import { socketmesh } from "@mr-aftab-ahmad-khan/socketmesh";

socketmesh.channel("orders");
```

## Why

WebSocket scaling becomes extremely complex quickly.
