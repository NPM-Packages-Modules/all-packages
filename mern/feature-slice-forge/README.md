# feature-slice-forge

**Topics:** feature · vertical-slice · scaffold · mern · mern-packages · merndev · nodejs · npm-pm · typescript

Generate an **entire feature vertically** — backend model/routes plus frontend page, hooks, and types in one shot (feature-first, not layer-first).

## Install

```bash
npm install feature-slice-forge
```

## API

```typescript
import { featureSliceForge } from "feature-slice-forge";

const slice = await featureSliceForge.create("invoice");
```
