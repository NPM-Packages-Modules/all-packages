# apiflowx

Visual API orchestration for MERN systems.

## Features

- route mapping
- dependency graphs
- latency monitoring
- API replay
- request simulation

## Example

```ts
import { apiflowx } from "@mr-aftab-ahmad-khan/apiflowx";

apiflowx.inspect(app);
```

## Why

Teams lose visibility in growing backend architectures.
