# apidocsmith

Generate beautiful API docs directly from Express routes.

## Features

- Swagger generation
- request examples
- response examples
- auth docs
- version tracking

## Example

```ts
import { apidocsmith } from "@mr-aftab-ahmad-khan/apidocsmith";

apidocsmith.scan(app);
```

## Why

API documentation is usually outdated or missing.
