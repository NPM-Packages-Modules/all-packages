# deploysense

Detect risky deployments before production.

## Features

- env verification
- dependency mismatch checks
- migration validation
- memory forecasts
- rollback alerts

## Example

```ts
import { deploysense } from "@mr-aftab-ahmad-khan/deploysense";

deploysense.verify();
```

## Why

Many outages happen due to unnoticed deployment issues.
