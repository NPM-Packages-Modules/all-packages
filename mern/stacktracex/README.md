# stacktracex

Visual distributed error tracing for MERN microservices.

## Features

- request tracing
- service timelines
- error replay
- correlation IDs
- latency visualization

## Example

```ts
import { stacktracex } from "@mr-aftab-ahmad-khan/stacktracex";

stacktracex.track(app);
```

## Why

Debugging across services is operational chaos.
