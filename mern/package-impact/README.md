# package-impact

**Topics:** npm · dependencies · bundle · audit · mern-packages · merndev · nodejs · npm-pm · typescript

Analyze **dependency additions before install** — transitive count, bundle impact, and known issues.

## Install

```bash
npm install package-impact
```

## API

```typescript
import { packageImpact } from "package-impact";

packageImpact.analyze("axios");
```
